# java-calculator-precourse

## 기능 목록

### 안내문 출력 및 사용자 입력

- "덧셈할 문자열을 입력해 주세요." 문구를 출력합니다.
- readLine()을 통해 사용자 입력을 받습니다.
- 입력값이 비어있을 경우, 0으로 처리합니다.

### 구분자 분석 및 숫자 추출

- 기본 구분자 : 쉼표(,) 또는 콜론(:)을 가집니다.
- 커스텀 구분자 : 문자열 앞부분의 //와 \n 사이에 위치하는 문자를 커스텀 구분자로 지정할 수 있습니다.
- 확인된 구분자(기본 또는 커스텀)를 기준으로 전체 문자열을 분리하여 숫자 리스트를 반환합니다.

### 계산 기능

- 분리된 숫자 리스트의 합계를 계산하여 반환합니다.

### 결과 출력

- "결과 : " 문구와 함께 최종 합계를 출력합니다.

## 예외 처리

- 잘못된 값을 입력한 경우, IllegalArgumentException을 발생시키고 애플리케이션을 종료합니다.
    - 음수가 포함된 경우
    - 구분자를 제외한 다른 문자가 포함된 경우
    - 커스텀 구분자로 숫자를 지정한 경우
    - 커스텀 구분자 문법은 사용했으나, 구분자가 지정되지 않은 경우
    - 커스텀 구분자 지정문자가 올바른 위치에 있지 않은 경우

## 테스트 케이스

#### 정상 동작 테스트

- **커스텀 구분자 사용**
- **연속된 구분자 처리** : '1,,2'와 같이 구분자가 연속으로 나오는 경우
- **정규식 특수문자 구분자**: '*'와 같이 정규식에서 특별한 의미를 갖는 문자르르 커스텀 구분자로 사용하는 경우

#### 예외 발생 테스트

- **예외 테스트**
- **허용되지 않은 문자 포함**: '1,a,2'와 같이 숫자가 아닌 문자가 포함된 경우
- **커스텀 구분자 형식 오류**: '//;\n1:2;3'와 같이 커스텀 구분자를 선언하고도 다른 구분자를 사용한 경우
